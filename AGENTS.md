# Local Registry

This tool runs `https://hub.docker.com/_/registry` in docker for managing a local image registry which is to be used with k3d, kind etc. for development purposes.

## TUI

Has a TUI for:
- adding a new image
- listing available images and repositories
- deleting tags, images, repositories
- view the registry container logs.
- show the registry container status in the bottom.


## CLI

CLI subcommands for making it work with scripts.
